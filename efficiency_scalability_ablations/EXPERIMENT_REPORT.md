# 4.6 效率、可扩展性与消融实验

后续已补充[二阶 HVP 与真正无 HVP Graph 的在线对照](second_order_online/EXPERIMENT_REPORT.md)，包含真实训练计时与子集重训。下文保留原缓存阶段实验，不能替代该在线对照。

## 目的与设置

本轮检验两个问题：稀疏图在语料规模扩大时的实际资源开销，以及各图模块对归因诊断与数据选择的影响。结果不预设 Graph 或全部模块必须占优。

- 模型与数据：复用 GPT-2 / Pile 100k 主实验缓存，语料指纹为 `4db35bdcf9cd4d40`。原代码只训练 GPT-2 最终 LayerNorm 的 1536 个参数，序列长 128；不是全参数微调。本轮不重新训练模型。
- 效率：固定 clean seed 0，按同一个随机排列取嵌套的 1k/10k/50k/100k 子集，每个规模独立进程重复 3 次。GPU 为 RTX 3090，CPU 使用 4 线程。
- 对照：分块精确余弦 KNN（GPU，k=10，chunk=512）、FAISS HNSW（CPU，M=32，efConstruction=80，efSearch=64）和逐点缓存分数重放。分别测量建图、门控、评分重放和 10% 选择。
- 消融：相同的 10k 子集，3 个缓存训练种子、干净/污染两种情景、一阶/二阶，14 组配置，共 168 个单元。默认 k=10、alpha=0.2、lambda_fraction=0.05；完整检查 k、alpha、lambda、表示选择、门控、历史、配对和尺度匹配。
- 指标：噪声 AUROC、所选集合污染率、固定参考图上的冗余与覆盖率、领域熵与数量、跨种子排序相关性。所有配置都保留，不按胜负筛选。

10k 消融使用的是 100k 训练缓存的子集，不是另行训练的 10k 模型。各污染子集比例分别为 9.93%、10.13%、10.06%。

## 效率结果

时间为均值（样本标准差），单位秒；重复的是计时，不是三次训练。

| 语料数 | 精确 GPU KNN | HNSW CPU KNN | ANN Recall@10 |
|---:|---:|---:|---:|
| 1,000 | 0.004 (0.001) | 0.068 (0.002) | 99.910% |
| 10,000 | 0.042 (0.003) | 0.976 (0.023) | 99.792% |
| 50,000 | 0.411 (<0.001) | 8.524 (0.029) | 99.716% |
| 100,000 | 1.355 (0.009) | 20.640 (0.421) | 99.632% |

100k 下，精确图的梯度门控为 **5.782 (0.019) 秒**，超过建图时间。一阶/二阶重放的摊销开销为 **0.053 / 0.137 毫秒每批**。建图、门控、重放和选择四项之和为 **8.416 / 9.466 秒**；不包含读取缓存、提取梯度和训练时间。

精确图各阶段最大额外 PyTorch 显存分配为 **684.344 MiB**。稀疏邻接数组为 **7.629 MiB**；加上门控权重、置信度和两阶分数后为 **12.589 MiB**。这些是未压缩数组大小，不是整个实验缓存。输入张量为 440.216 MiB，HNSW 序列化索引为 318.929 MiB。

HNSW 的最终分数与精确图的 Spearman 约为 0.99980，10% 所选集合重合率一阶/二阶为 99.873% / 99.817%。它在本机减少了建图对 GPU 的依赖，但没有赢得速度；这不是同硬件上的算法对比，也不能据此断言更大规模下的速度关系。

## 消融结果与解释

下表展示预先选定的主要模块，其余配置见完整结果。AUROC 为均值（种子间样本标准差）；稳定性是三个种子对的平均 Spearman，不是独立重复实验的置信区间。

| 配置 | 一阶噪声 AUROC | 二阶噪声 AUROC | 一阶排序稳定性 | 一阶覆盖率 |
|---|---:|---:|---:|---:|
| 完整 Graph | 0.55376 (0.01010) | 0.55334 (0.01050) | 0.21159 | 0.74557 |
| 无门控 | 0.56170 (0.00584) | 0.56126 (0.00640) | 0.18681 | 0.74623 |
| 无历史扩散 | 0.55027 (0.01194) | 0.54984 (0.01223) | 0.17094 | 0.76913 |
| 无尺度匹配 | 0.55101 (0.01180) | 0.55060 (0.01229) | 0.18020 | 0.76593 |

1. **历史扩散存在权衡。** 相比无历史的一阶版本，完整版本排序稳定性提高，但参考图覆盖率从 0.76913 降至 0.74557，不能同时宣称更稳定且更多样。
2. **门控并非所有任务都有益。** 去掉门控后，两阶噪声 AUROC 和所选集合污染率都改善；与此同时，排序稳定性下降。本轮不支持门控在噪声识别上的正向结论。
3. **多样性惩罚收益较小。** 默认 lambda 相比 lambda=0，使一阶/二阶单位样本配对冗余下降约 1.63% / 1.85%，覆盖率仅小幅改善。lambda 只影响选择，所以不应改变分数级 AUROC 或排序稳定性。
4. **配对项影响有限。** 二阶完整版本与去掉配对项的 AUROC 分别为 0.55334 与 0.55332，不能据此主张有意义的提升。一阶不含配对项，因此对应消融应当完全相同，检查已通过。

绝对噪声 AUROC 仅约 0.55，完整方法所选集合的污染比例仍约为 10.4%–10.5%，没有显示出强噪声排除能力。上述是描述性结果，未进行显著性或普遍优越性声明，也未据此调整主实验参数。

## 完成项与边界

- 已完成四规模共 12 个计时单元（168 个阶段测量）、168 个消融单元、84 个干净分数向量的检查；图已生成 PNG/PDF/SVG 并检查显示。
- 新消融实现与原 `replay_graph_trajectory` 在六组测试中逐值一致；精确 KNN 对照暴力计算、自邻居排除、零强度退化及子集嵌套检查通过。原主实验代码和输入缓存未修改。
- **本轮是缓存阶段的效率与机制诊断，不是完整端到端实验。** 当前实现按随机顺序重放已经缓存的分数，并非恢复原训练轨迹。每批重放耗时不能标作真实在线图更新延迟。
- 文档要求的完整归因 wall time、真实在线更新开销及各消融的重新训练 validation loss/accuracy 尚未测量。本轮结果不能替代这些数据，也不能证明论文完整动态图公式已被复现。
- 精确内存分配可能重复一致；极小计时波动会被三位小数舍入成零。完整 CSV/JSON 保留原始精度，未添加人为方差。
